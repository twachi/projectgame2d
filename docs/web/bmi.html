โปรแกรมคำนวณ BMI (เด็ก–ผู้ใหญ่)

รองรับการตีความตามอายุและเพศ (CDC 2–20 ปี: LMS/Z-score) + เกณฑ์ผู้ใหญ่
–
ค่า BMI
กรอกข้อมูลด้านบนแล้วกด “คำนวณ” เพื่อดูเปอร์เซ็นไทล์/เกณฑ์สุขภาพและคำแนะนำเฉพาะวัย

วิธีคำนวณ (สรุป)

  1. คำนวณ BMI = น้ำหนัก(กก.) / (ส่วนสูง(ม.)²)
  2. ถ้าอายุ < 20 ปี → แปลงเป็น z-score และ เปอร์เซ็นไทล์ ด้วยพารามิเตอร์ L, M, S ตามอายุ(เดือน)และเพศ
  3. จัดกลุ่ม: ต่ำกว่า 5th = น้ำหนักน้อย, 5th–<85th = ปกติ, 85th–<95th = น้ำหนักเกิน, ≥95th = อ้วน
  4. ถ้าอายุ ≥ 20 ปี → ใช้เกณฑ์ผู้ใหญ่ (เอเชียตะวันออกเฉียงใต้)

อ้างอิง

  • CDC Growth Charts (2000) – ไฟล์ bmiagerev.csv (LMS รายเดือน 2–20 ปี)
  • CDC Extended BMI-for-Age (2022) – สำหรับค่ามากกว่า 95th
  • WHO 5–19 ปี – ความหมายของ +1SD/+2SD

หมายเหตุ: แอปจะพยายามดาวน์โหลดตาราง LMS จาก CDC อัตโนมัติ หากเครือข่าย/CORS ไม่อนุญาต จะใช้ข้อมูลสำรอง (interpolation รายปี) ซึ่งความแม่นยำใกล้เคียง แต่ไม่เท่ารายเดือน

สร้างเพื่อการศึกษา ไม่ใช่เครื่องมือวินิจฉัยทางการแพทย์ หากมีข้อกังวลด้านสุขภาพโปรดปรึกษาแพทย์
